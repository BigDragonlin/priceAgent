# 项目目标与范围

- **项目名**：priceAgent 报价助手。
- **产品目标**：依据原料成本、运输费用、市场需求、利润比例和用户规则生成报价方案；需求还包含市场数据接口和利用历史反馈改进报价。详见仓库根的 `需求文档.md`，这些是需求，尚未逐项验收。
- **本仓库范围**：前端页面、参数输入、报价结果展示及与后端的接口配合。前端在 `frontend/`，后端在 `backend/`（与前端共用根 Git 仓库）。
- **当前授权（2026-09-12 报价 Demo）**：用户已同意制作可运行 Demo，并明确允许保留 `需求文档.md` 的旧改动继续写入。前端在 `frontend/`，计算和 Skill API 在 `backend/` 实现。
- **约束**：遵守根级 AGENTS.md 的用户约定，不处理 CI/CD，不修改全局工具配置。
- **本次成功标准**：总 Skill 加子 Skill、后端模块化计算、参数建议及确认、报价结果和真正的 xlsx 导出贯通；用计算测试和 ego-browser 验证。实时市场、自主学习、报价生命周期不属于 Demo。使用用户指定的 DeepSeek deepseek-flash 真实接口，模型未配置或失败时明确报错，不回退 Mock。
- **角色**：用户决定范围；Codex 执行；交付前由不同模型独立评审。
